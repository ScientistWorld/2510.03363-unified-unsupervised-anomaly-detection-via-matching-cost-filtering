# Experiment Overview

## rgb_mvtec_multiclass

Tests the central visual anomaly-detection claim in a compact multi-class RGB setting. The experiment asks whether a submitted system can improve anomaly image ranking and pixel localization over the packaged baseline while using the same data split, image resolution, and evaluation artifact format.

The score includes threshold-free ranking metrics, thresholded F1 operating-point metrics, low-false-positive localization metrics, per-category means, and machine-independent overhead constraints for added parameters and FLOPs.
