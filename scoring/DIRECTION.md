# Research Direction

Work within unsupervised multi-class visual anomaly detection: a single model, trained on normal images only, must score every test image and produce a pixel heatmap for 15 MVTec-AD categories. The reference compares each input with a few normal images of its category in a frozen pretrained feature space, and refines that comparison with a component learned from normal images plus synthetic anomalies.

Valid improvements make the evidence from that comparison more reliable at the same operating point. Examples: how the input-to-template matching is represented and refined, how the few reference images are chosen, how learned and raw evidence are combined into maps and image scores, and how the learned part is trained on synthetic anomalies (synthesis, objectives, schedules). The measure of success is detecting and localising defect types the method has never seen. The ranked half of the test set holds defect types absent from the visible half.

Out of bounds (see `scoring/CONSTRAINTS.md`): training on real anomalies, including the visible development answers; any use of the hidden answers or of public MVTec-AD test annotations; a larger or fine-tuned feature extractor or higher resolution; more than three normal reference images per input, or a training-set memory bank; scoring a test input with information from other test inputs; external anomaly datasets.
